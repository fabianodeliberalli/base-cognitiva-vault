# Fontes dos slides de gravação de M3 (26/11/2026)

- `decks_m3.py`: as oito aulas de M3, com os tipos de tela de `../../../Módulo 2/Slides de gravação 29-11/Fontes/base.py` (mesma identidade visual de M2).
- `guia_gen.py`: gera o guia de gravação a partir das notas dos PowerPoint.
- Para reconstruir: copie `base.py`, `tsh_lib.py`, `anim.py` e `assets/` (de [[Padrão de Slides - ferramentas/README|Padrão de Slides - ferramentas]]) para a pasta dos scripts e rode `python decks_m3.py`.

Forma das notas igual à de M2: função entre colchetes na primeira linha; uma frase por linha; « » para o que se diz como está; [PAUSA]; → para a tela seguinte. Cada aula fecha com a tela do Cultivo do Eixo (versão do Módulo 3).
