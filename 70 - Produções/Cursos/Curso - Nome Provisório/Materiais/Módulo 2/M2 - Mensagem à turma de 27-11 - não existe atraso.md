Mensagem para o grupo da turma (enviar antes do encontro de sábado, 28/11)

Oi, pessoal! Uma notícia sobre o ritmo do curso.

Não existe atraso no TSH. Se você não conseguiu fazer tudo do Módulo 1, está tudo bem: perder o ritmo não significa perder o percurso, e isso vale para o curso também.

Três mudanças, a partir do retorno de vocês:

1. No sábado, começo o encontro com o Módulo 1 em prática guiada: dez minutos, sem precisar escrever nada. Fica gravado no Módulo 1 para quem quiser fazer de novo.
2. A partir do Módulo 2, as práticas são guiadas dentro dos próprios vídeos: é só fazer junto. Escrever é opcional, para quem gosta; os materiais escritos são apoios curtos, de uma página.
3. Cada módulo terá um caminho mínimo, para as quinzenas com pouco tempo: duas aulas e a prática diária de 3 a 5 minutos, o Cultivo do Eixo, que apresento no sábado.

O calendário agora é quinzenal. Um pouco por dia vale mais do que tudo de uma vez.

Até sábado!
