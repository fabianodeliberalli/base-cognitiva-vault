# 7. Privacidade sem perder o acesso do GPT (pergunta 6)

O ChatGPT consegue ler repositórios privados, desde que você conecte a sua conta do GitHub a ele. O suporte da OpenAI explica que se conecta o GitHub pelas configurações, na área de aplicativos, e que é preciso autorizar quais repositórios o ChatGPT acessa. O mesmo suporte avisa que a disponibilidade varia conforme o plano e o modo de uso: alguns planos permitem o GitHub na pesquisa aprofundada ou no modo agente, mas não na conversa comum. Há também relatos de usuários que só conseguem ler repositórios privados por esses modos.

**Por isso, a ordem segura é testar antes:**

1. **No ChatGPT:** Configurações → Aplicativos → GitHub → conectar. Na tela do GitHub, escolha "Only select repositories" e marque `base-cognitiva-vault`.
2. **Teste no modo que você usa:** peça ao GPT para abrir um arquivo específico do repositório, por exemplo o Raio X vigente. Como o repositório ainda é público, esse primeiro teste só confirma que a conexão funciona.
3. **Se funcionar,** me diga "sim, torne privado". Eu faço a mudança e você repete o teste na hora. Se o GPT parar de ler, eu volto o repositório para público em segundos.
4. **No Obsidian,** confira logo depois se a sincronização continua. Se ela já usa o seu acesso autenticado, nada muda.

**Se o GPT não conseguir ler o repositório privado no modo que você usa,** há uma alternativa: manter o repositório público e tirar só o Banco Fenomenológico para um repositório privado separado. O GPT continua lendo todo o resto. A desvantagem é apagar o Banco do histórico do repositório público, o que reescreve o histórico e exige uma nova cópia no Obsidian. Eu conduzo, mas é mais trabalhoso.

Em qualquer caso, antes de gravar os casos de M2.4 e M2.6, é preciso o consentimento escrito das pessoas.

Fontes: [Connecting GitHub to ChatGPT — OpenAI Help Center](https://help.openai.com/en/articles/11145903-connecting-github-to-chatgpt-deep-research); [relato de usuários sobre repositórios privados](https://community.openai.com/t/private-github-repos-not-accessible-in-pro-only-accessible-via-deep-research-codex/1379905).
