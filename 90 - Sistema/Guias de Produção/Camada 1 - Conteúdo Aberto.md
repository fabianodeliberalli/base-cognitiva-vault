# Guia Operacional — Camada 1 — Conteúdo Aberto

**Status:** rascunho operacional para validação

## Função no ecossistema

Abrir uma nova forma de perceber a experiência humana, produzir reconhecimento e deslocar paradigmas sem entregar antecipadamente toda a profundidade do método.

## Público

Pessoas que ainda não conhecem o projeto ou que reconhecem sofrimento, confusão ou padrões recorrentes, mas ainda não possuem uma linguagem integrada para compreendê-los.

## Transformação esperada

- **Entrada:** experiência interpretada como defeito, desorganização isolada ou problema sem sentido.
- **Movimento:** tradução acessível que revela lógica, função, contexto e possibilidade de compreensão.
- **Saída:** reconhecimento, curiosidade qualificada e abertura para aprofundamento.
- **Ponte:** direcionar naturalmente para o Workshop quando houver prontidão.

## Produções usuais

- vídeos;
- posts;
- textos curtos;
- séries editoriais;
- metáforas e casos não identificáveis;
- conteúdos de mudança de paradigma.

## Deve fazer

- partir de experiências humanas reconhecíveis;
- traduzir conceitos sem banalizá-los;
- favorecer reorganização da percepção;
- demonstrar a singularidade do projeto;
- deixar uma questão ou tensão que convide ao próximo passo.

## Não deve fazer

- funcionar como aula teórica extensa;
- entregar todo o Método EIXO;
- diagnosticar pessoas;
- prometer transformação clínica;
- usar sofrimento apenas como gatilho de marketing;
- confundir simplificação com superficialidade.

## Critérios de qualidade

- A pessoa se reconhece sem ser reduzida a uma categoria?
- O conteúdo muda a forma de olhar ou apenas informa?
- A linguagem é acessível e intelectualmente íntegra?
- O nível de profundidade pertence ao conteúdo aberto?
- Existe uma ponte coerente para o Workshop?
