# Base Cognitiva — Vault

Este vault é a memória persistente do projeto e do trabalho intelectual de Fabiano.

## Estrutura

- `00 - Caixa de Entrada`: materiais brutos ainda não organizados;
- `10 - Fontes`: fichas e registros de origem;
- `20 - Notas Conceituais`: ideias, conceitos, sínteses e hipóteses;
- `30 - Paradigmas`: paradigmas candidatos e validados;
- `40 - Metáforas`: metáforas organizadas e suas aplicações;
- `50 - Relações`: relações estruturantes que exigem registro próprio;
- `60 - Sessões`: pacotes e memórias resumidas de sessões;
- `70 - Produções`: produtos em desenvolvimento e versões aprovadas;
- `90 - Sistema`: guias operacionais, índices e regras da base.

## Fluxo principal

1. O material entra na Caixa de Entrada.
2. O ChatGPT consulta, relaciona, desenvolve e produz.
3. Ao final, gera um pacote de registro.
4. Fabiano escolhe o que merece permanecer.
5. O Codex registra os itens aprovados.
6. O Codex verifica, versiona e sincroniza com o GitHub privado.

## Regras

- materiais brutos não são alterados;
- nem toda conversa vira memória;
- relações precisam ter justificativa e utilidade;
- hipóteses permanecem hipóteses;
- decisões humanas devem ser distinguíveis das interpretações da IA;
- o vault não contém agentes, scripts ou configurações técnicas do Codex.
